# vidcite

Ask a question about a small library of Creative Commons YouTube talks and get a short answer
whose citations jump an embedded player to the second the claim is made.

Source, setup and evaluation: https://github.com/NishithVadlamudi/vidcite

This demo has usage limits (10 questions per visitor per hour, and a daily cap on generated
answers). Past the cap, it shows the best matching moments without a generated answer.
